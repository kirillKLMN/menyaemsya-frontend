# Меняемся: дизайн-система

## Типографика

| Токен | Шрифт | Применение |
| --- | --- | --- |
| `--font-body` | Onest | Основной текст, навигация, кнопки и подписи. Загружаются начертания 400, 500, 600 и 700. |
| `--font-heading` | Ubuntu Medium (500) | Основные заголовки и логотип. |
| `--font-accent` | Snell Roundhand | Декоративные рукописные акценты, не для длинного текста и элементов управления. |

Onest и Ubuntu 500 загружаются из Google Fonts. Для Snell Roundhand задан стек `Snell Roundhand`, `URW Chancery L`, `cursive`; лицензированный web-font для него пока не подключён.

Figma MCP не обнаружил в исходном файле локальных color variables. Перечисленные CSS-переменные сохраняют палитру, заданную проекту; не следует считать их синхронизированными Figma variables. В узле Header MCP подтвердил `#2F5BEA`, `#68778D`, `#000000`, `#FFFFFF` и нижнюю границу `#DFE6EF`. Для границы отдельный токен не добавлен, так как он не нужен другим текущим базовым стилям.

## Базовые стили

- Универсальный reset задаёт `box-sizing: border-box` для элементов и псевдоэлементов.
- `body` сбрасывает margin и использует `--font-body` и `--color-text`.
- Глобальные стили кнопок, ссылок и заголовков не задаются; компоненты сохраняют контроль над собственной геометрией и оформлением.

## Header: точные параметры Figma MCP

Измерения относятся к узлу `58:24` в desktop-фрейме 1440 × 88 px. Координаты указаны относительно фрейма.

| Элемент | Размер и координаты | Типографика и оформление |
| --- | --- | --- |
| Header | 1440 × 88 px, начало `(0, 0)` | Фон `rgba(255,255,255,0.5)`, blur 20 px, нижняя граница 2 px `#DFE6EF`. |
| Внутренние отступы | слева и справа по 70 px | Контент не ограничен фиксированной шириной страницы. |
| Логотип | 125 × 29 px, `(70, 29.5)` | Ubuntu Medium 25 px, `#000000`. |
| Группа навигации | 236 × 20 px, `(526.5, 34)` | Onest Regular 16 px, `#68778D`; gap 36 px. |
| «Каталог» | 61 × 16 px, `(530, 36)` | Onest Regular 16 px, `#68778D`. |
| «Как это работает» | 132 × 20 px, `(627, 34)` | Onest Regular 16 px, `#68778D`. |
| «Войти» | 103 × 54 px, `(1094, 17)` | Onest Medium 17 px, текст и border `#2F5BEA`, border 1 px, фон `rgba(255,255,255,0.3)`, radius 18 px. |
| «Регистрация» | 159 × 54 px, `(1211, 17)` | Onest Medium 17 px, белый текст, фон `#2F5BEA`, radius 18 px. |
| Между кнопками | 14 px | Группа кнопок: 276 × 54 px, начало `(1094, 17)`. |

Desktop-группы распределены по принципу `space-between`: логотип, навигация и группа действий — три элемента одной строки. Навигация не центрируется относительно страницы.

## Header: адаптивные значения реализации

Эти значения не указаны в данных узла 58:24 и оставлены как параметры текущей адаптивной реализации:

| Параметр | Текущее значение |
| --- | --- |
| Breakpoint мобильного меню | 800 px и ниже |
| Высота мобильной шапки | не менее 66 px |
| Горизонтальные поля на мобильном | 16 px |
| Размер логотипа на мобильном | Ubuntu Medium 20 px |
| Область кнопки меню | 44 × 44 px |
| Desktop horizontal padding вне ширины 1440 px | `clamp(24px, calc(5vw - 2px), 128px)` |
